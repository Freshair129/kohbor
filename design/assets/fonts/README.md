# Bundled font specimens

Unmodified Noto Sans Thai and Noto Sans Regular/Bold from the installed `fonts-noto-core` distribution. The original name tables, outline bytes and copyright metadata are preserved. Upstream: https://github.com/notofonts/noto-fonts. License: [SIL Open Font License 1.1](OFL-Noto.txt).

These fonts are embedded in the standalone design board for offline Thai and Latin rendering. Production font packaging should retain this license and validate shaping and weight fallback on Windows/WebView2. Medium and semibold weights use normal CSS fallback to the supplied regular/bold faces; dedicated weight files are not supplied.
