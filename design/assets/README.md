These SVG paths were authored for Kohbor in this design task. They contain no inherited game portraits, commercial mascot, reference-brand artwork or external image dependency. The mint and ink literals are the asset rendition of the corresponding semantic colors in the token source; changes require regenerating or reviewing these assets together. No trademark clearance or product approval is asserted.

Use the mint mark on a dark neutral surface. Use an accessible text name beside it; if adjacent text repeats its name, mark the image decorative. Do not stretch, rotate, add a glow, replace its colors with status colors, or use the companion as an alert. Keep the companion away from the live minimap and urgent notice area. The board's line icons are original simple SVG constructions using a 24-unit grid and 1.75-unit strokes.

Fonts, if included in `fonts/`, retain their own accompanying license and source record. Font choice is independent of these original vector shapes.
