Design proposal. Not approved (DEC-VISUALS open). Sample data only. Nothing here replaces application code. Identity tokens (A1, E1, names) and the minimap picture are neutral placeholders, not game artwork.

Glance mode and detail mode

Glance is the default while a match is live: nothing needs the mouse, the rail recedes, and only values that can be read from one metre are shown. Detail appears when the pointer enters the window or a key is pressed, and leaves after a quiet period. Detail only fills space that glance already reserved, so nothing moves. The Share list indicator and the pause control are visible in both.

Share list indicator: always on the deck

There is no per-match prompt, so the deck itself says, in every match, who receives what. It names the people and the scopes, sits at the top of the own-team column, and has a one-press pause next to it in both modes. Resume is always an explicit press.

Idle and no-match states

No seeded roster and no demo numbers. The layout keeps its regions so the eye finds the map in the same place when the match starts.

Always-on-dark, and the light theme

The tokens follow prefers-color-scheme with a data-theme override, as the shipped tokens require. The Live deck is the one surface that pins data-theme="dark" by default: a bright panel beside a dark game costs peripheral contrast and night vision. The user can set it to follow the system or to light. The captured picture and its markers keep fixed colours in both themes because the game image is dark either way.

Burn-in avoidance without moving the map

  • No pixel shifting during a match. Shifting would break the 1-px map stability rule and blur peripheral position memory.
  • Low static luminance instead. Permanent chrome (rail, card borders, frame) uses the line and surface tokens only. Bright fills are reserved for transient states: the critical frame, a missing card, the new-sighting ring.
  • The largest area is video. The map content changes every frame; the overlay markers move with the game.
  • Idle dims and relocates. With no match for a set time, the deck drops to the idle state shown above. The idle mark changes position in discrete steps (no animation) between a few fixed places. A new match restores the layout at once.
  • Not verified. None of this has been tested on an OLED or plasma panel; see DESIGN-NOTES.
