Rules the cards follow

  • Identity tokens are neutral placeholders: a ring with a slot label for allies, a diamond for enemies. The same shape and label are used on the map. No portraits, no game art.
  • HP is a neutral bar plus the number. There is no green. Mana is a thinner blue bar plus a percentage, because the peer contract carries mana as a percentage only.
  • State is carried by border style, a glyph and words together: solid = fresh, dashed = stale / not shared / unknown, hatched token = dead, double outline = selected.
  • No hover-only information. Everything a card knows is printed on it, or is in the inspector reached by Enter.
